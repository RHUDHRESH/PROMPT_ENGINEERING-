# Exp-8: Reproducing an Image Using Prompts

**Due:** 14 Sep 2026 · **Reference repo:** RaajaThilahar/Ex.No.8

## Steps
1. Put the given image in `reference_image/`.
2. Fill `analysis.md` (objects, colours, lighting, composition, style).
3. Write prompts v1 -> vN in `prompts/iterations.md`.
4. Generate with DALL·E / Stable Diffusion / Midjourney; save images to `generated_images/v1.png`, `v2.png`, ...
5. Document differences in `observations.md`.
