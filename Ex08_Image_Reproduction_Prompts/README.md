# Exp-8: Reproducing an Image Using Prompts

**Due:** 14 Sep 2026 · **Reference repo:** RaajaThilahar/Ex.No.8

## Steps
1. The course reference image was not included with the supplied instructions, so this experiment uses a clearly labeled sample landscape generated for the exercise at `reference_image/sample_reference.png`.
2. Its objects, palette, lighting, composition and style are documented in `analysis.md`.
3. The exact prompts and one targeted refinement are recorded in `prompts/iterations.md`.
4. Two generated results are saved in `generated_images/`.
5. `observations.md` records a visual comparison. Scores are one-person subjective judgments from a single pair of generations, not a benchmark.

**Tool:** built-in image generation in Codex. The tool does not expose a repeatable seed or a model-version label in this workflow. The sample reference and both results are generated images, not a supplied course image.
