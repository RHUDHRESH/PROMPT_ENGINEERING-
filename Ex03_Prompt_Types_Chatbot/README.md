# Ex-3: Prompt Engineering Types — Customer Support Chatbot

**Due:** 21 Aug 2026 · **Reference repo:** RaajaThilahar/Ex.No.3

## Aim
Understand four prompting types by designing a chatbot for **product troubleshooting, order tracking and general inquiries**, then compare AI tools.

## Types covered
1. **Straightforward prompt** — direct instruction. `prompts/1_straightforward.md`
2. **Tabular format prompting** — ask for / supply a table. `prompts/2_tabular.md`
3. **Missing-word (cloze) prompting** — model fills blanks. `prompts/3_missing_word.md`
4. **Preceding-question prompting** — ask clarifying/prior questions first. `prompts/4_preceding_question.md`

## Workflow
Run every prompt on two tools -> save under `outputs/` -> score in `evaluation.md`. `types_explained.md` holds the short explanations + examples for the write-up.
