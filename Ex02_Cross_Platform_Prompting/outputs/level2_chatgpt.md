# Level 2 (Role) — ChatGPT output

## Why transformers changed language technology

Transformers became the leading architecture for sequence modelling because self-attention lets a model compare tokens across an entire input at once. This helps capture long-range relationships and allows efficient parallel training. Large language models (LLMs) learn to predict the next token, then instruction tuning helps them respond to requests. Their output can still be wrong or biased, and training and use require substantial compute. Current work explores retrieval, efficiency and more reliable evaluation.
