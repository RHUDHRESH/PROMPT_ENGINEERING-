# Level 4 (Constraint) — ChatGPT output

Transformers compare text pieces at once, which helps connect distant ideas and speeds training. Large language models (LLMs, text-prediction systems) learn by predicting the next piece, then use examples to follow instructions. They can invent facts, repeat data bias and cost much to run. Document lookup adds useful sources when answering. Longer input limits do not guarantee correct answers.
